Project Abstract

Port LittleFS v2 into RTEMS as a native filesystem integrated with the RTEMS VFS layer, enabling reliable flash-based storage with wear leveling and power-loss resilience, while ensuring forward compatibility for LittleFS v3.

Project Scope

Medium (approx. 175 hours)

Project Description

RTEMS currently lacks a lightweight, flash-optimized filesystem suitable for embedded systems with constrained memory and power-loss scenarios. LittleFS addresses this gap by providing a small, resilient filesystem designed for microcontrollers.

This project will integrate LittleFS into RTEMS under /contrib and implement a wrapper layer mapping RTEMS VFS operations to LittleFS APIs. This will provide RTEMS with a modern, robust filesystem alternative suitable for flash storage. I chose this project due to my background in embedded systems and prior work on a demo LittleFS patch for RTEMS.

Maintenance will be ensured by keeping the wrapper modular and well-documented, enabling future contributors to extend or maintain the code easily.

Project Deliverables

- LittleFS v2 integrated under /contrib
- RTEMS VFS wrapper implementation
- Block device interface integration (read/prog/erase/sync)
- Support for file operations (open/read/write/close/lseek)
- Directory operations (readdir, mkdir, traversal)
- Metadata operations (stat, statvfs, rename, truncate)
- Test application and validation
- Documentation (design + usage + tutorial)
- Future contributor guide for continuation (v3 support)
