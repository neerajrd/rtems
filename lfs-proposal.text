Project Abstract

Port littlefs v2 into RTEMS as a native filesystem. After completing v2 integration, the project will explore and provide initial integration for littlefs v3.

>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>

Project Scope

Medium Project (175 hours)

>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>

RTEMS supports flash-based filesystems such as JFFS2; however, there is a need for a lightweight, modern alternative optimized for constrained embedded systems such as microcontrollers. littlefs addresses this by offering low footprint, low RAM usage, fast mount times, and a simple design specifically designed for microcontroller environments.

This project will integrate littlefs into RTEMS under the /contrib directory and implement a wrapper layer that maps RTEMS VFS operations to littlefs APIs. The design will follow an approach similar to the existing JFFS2 integration, providing RTEMS with a compact and robust alternative for flash storage.

After completing the littlefs v2 integration, the project will explore and provide initial integration for littlefs v3, which is currently under development.

In addition, documentation will be created, including API-level documentation similar to the RTEMS JFFS2 documentation (Doxygen-based), along with a usage guide for developers.

I chose this project due to my interest in embedded systems and C programming. I have also submitted a littlefs demo patch for RTEMS to show my familiarity with RTEMS, littlefs, and STM32 microcontrollers.
